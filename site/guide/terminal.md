# ターミナルの基本

blugit は、ターミナルにコマンドを打って使います。
ターミナルを使ったことがない人向けに、blugit を使うのに必要なことだけをまとめました。

## ターミナルとは

ターミナルは、文字でPCに指示を出すためのアプリです。
コマンドを1行打って Enter キーを押すと、PCがその指示を実行して、結果を文字で表示します。

## ターミナルを開く

| OS | 開き方 |
|---|---|
| Windows 11 | スタートボタンを右クリックして「ターミナル」を選ぶ |
| Windows 10 | スタートメニューで「PowerShell」と入力し、「Windows PowerShell」を開く |
| macOS | ⌘（command）+ スペースで Spotlight を開き、「ターミナル」と入力して Enter |
| Linux（Ubuntu） | Ctrl + Alt + T |

開くと、次のような1行が表示されて、入力を待っている状態になります。この行を**プロンプト**と呼びます。

## コマンドの打ち方

- このガイドのコマンドは、右上の「コピー」ボタンでコピーして、ターミナルに貼り付けてかまいません。
- 貼り付けは、Windows なら Ctrl+V、macOS なら ⌘V、Linux なら Ctrl+Shift+V です。
- 自分で打つときは、**日本語入力をオフ**にして半角で打ちます。全角の文字やスペースが混ざると、コマンドが動きません。

### `< >` は置き換える場所

コマンドの中の `< >` で囲まれた部分は、**自分の値に置き換える場所**です。`< >` そのものは入力しません。

<AnnotatedCommand
  command="blugit join {<接続コード>} {<登録名>}"
  :notes="[
    ['<接続コード>', 'ホストから聞いた12文字に置き換えます。例：00MX-8433-A77D'],
    ['<登録名>', '自分で決めた名前に置き換えます。例：demo'],
  ]"
/>

この例なら、実際に打つのは `blugit join 00MX-8433-A77D demo` です。

## フォルダを移動する

ターミナルは、いつもどこか1つのフォルダの中にいます。
`blugit host ./demo.git` のように、今いるフォルダを基準に場所を書くコマンドは、目的のフォルダへ移動してから実行します。

<AnnotatedCommand
  command="cd {<フォルダの場所>}"
  :notes="[
    ['フォルダの場所', '移動したいフォルダです。~ はホームフォルダ、.. はひとつ上のフォルダを表します'],
  ]"
/>

::: tip フォルダの場所を簡単に入力する
`cd ` と打って（最後にスペースを1つ入れて）から、エクスプローラーや Finder のフォルダをターミナルにドラッグ＆ドロップすると、そのフォルダの場所が入力されます。そのまま Enter を押せば移動できます。
:::

今いるフォルダは `pwd` で、中にあるものは `ls` で確かめられます。

## 困ったとき

| 操作 | 効果 |
|---|---|
| Ctrl + C | 実行中のコマンドを止める（`blugit host` もこれで止める） |
| ↑ / ↓ | 前に打ったコマンドを呼び出す |
| Tab | ファイル名やフォルダ名の続きを補完する |

コマンド名を打ち間違えると、「見つからない（not found）」といったメッセージが出ます。
blugit のエラーメッセージの意味は、[困ったとき](./troubleshooting)で調べられます。
