# blugitのしくみ（ざっくり）

実際に操作する前に、blugit の登場人物と流れをざっと押さえておきましょう。

## ホストとゲスト

| 役割 | どんなPC | 使うコマンド |
|---|---|---|
| <Role who="host" /> | リポジトリを公開するPC | `blugit host` で、bare リポジトリの共有を始める |
| <Role who="guest" /> | ホストに接続するPC | `blugit join` で登録し、`git clone blugit://登録名` で使う |

ゲストから見ると、[Git講座](../git/#map)の「Gitの地図」のリモート（みんなの置き場）が、**Bluetooth の先にあるホストのPC**になるだけです。

push や pull の矢印は、Bluetooth を通ってホストの bare リポジトリに届きます。
Gitの使い方そのものは変わりません。commit・push・pull は、これまでどおり AI に頼めます。

## 住所・合言葉・合鍵

blugit で相手とつながるときには、3つのものが登場します。

| たとえ | 実際のもの | 秘密か |
|---|---|---|
| 住所 | 接続コード（例：`00MX-8433-A77D`） | 秘密ではない |
| その場限りの合言葉 | 6桁の確認番号（1回限り、180秒で無効） | 登録のときに本人確認に使う |
| 合鍵 | 登録のときにお互いが保存する鍵 | 取り消せる |

### 接続コード＝住所

ホストが共有を始めると、12文字の接続コードが表示されます。
これは、ホストのPCの Bluetooth の「住所」と、接続口の番号を表したものです。ゲストはこれを使ってホストを見つけます。

住所なので、秘密ではありません。接続コードを知っているだけでは、登録はできません。

### 確認番号＝その場限りの合言葉

ゲストが接続コードで登録を申請すると、ホストの画面に6桁の確認番号が表示されます。
ホストの人がその番号をゲストに伝え、ゲストが入力すると登録が完了します。

番号を正しく入力できるのは、ホストの人から直接番号を聞いた相手だけです。
だからホストの人は、申請してきた端末の名前が目の前の相手のPCかどうか確かめてから、番号を伝えます。

### 鍵＝合鍵

登録が終わると、お互いのPCに相手の鍵が保存されます。
2回目からはこの鍵で自動的に相手を確かめ合い、通信も暗号化されるので、番号の入力はいりません。

ホストは、渡した合鍵をいつでも無効にできます（[アクセスを取り消す](./devices#アクセスを取り消す)）。

## 全体の流れ

| | 誰が | 何をする | いつ |
|---|---|---|---|
| 1 | <Role who="host" /> | `blugit host` で共有を始め、接続コードを伝える | 共有するたび |
| 2 | <Role who="guest" /> | `blugit join` で登録を申請し、ホストから聞いた確認番号を入力する | 最初の1回だけ |
| 3 | <Role who="guest" /> | `git clone blugit://登録名` で複製し、あとは push / pull | 毎回 |

実際の手順は、次のページの[インストール](./install)と[はじめての共有](./first-share)で説明します。
